MAISONÉ E-COMMERCE WEBSITE
==========================

Open index.html in your browser to run the website.

Pages:
- index.html       Home
- shop.html        Full catalog / search / category filters / sorting
- product.html     Product details
- cart.html        Cart with order summary
- checkout.html    Checkout demo
- about.html       About
- contact.html     Contact

Folders:
- css/style.css
- js/script.js

Design:
- Navy + orange visual system, Sora (headings) + Inter (body) fonts
- Sticky navy header with search bar, category nav, cart/wishlist counters
- Category grid, product grid with quick-add, ratings and tags
- Cart page with itemised order summary (subtotal, shipping, tax, total)
- Checkout page with contact/delivery form and order summary sidebar
- Dark/light mode saved in localStorage
- Product search, category filters and sorting (featured/price/name)
- Wishlist with badge, cart totals, DOM manipulation via localStorage state

NOTE:
Product photos use remote Unsplash image URLs so the project works immediately.
For a fully offline copy, download the images and replace the URLs in
js/script.js and the HTML files with local paths.
